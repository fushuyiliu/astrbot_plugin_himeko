# Security policy

Do not post credentials, private chat content, personal identifiers, or an
unredacted configuration file in a public issue.

For a suspected vulnerability, use the repository's private GitHub security
advisory channel once it is enabled. Until then, contact the maintainer through
the GitHub profile linked from the repository and include only the minimum
reproducible details. Please allow time for acknowledgement before public
disclosure.

Reports about exposed credentials should identify the affected file or service
without copying the secret into the report. Rotate or revoke the credential
first when you control it.
