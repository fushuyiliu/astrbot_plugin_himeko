# Himeko Companion for AstrBot

[English](README.en.md) | 中文

> Himeko 是以《崩坏：星穹铁道》中的姬子为角色背景，为 AstrBot 开发的非官方 AI 互动插件。

这是一个独立完成、可安装的 AstrBot 插件发布候选版。它提供可选的姬子风格互动补充提示、主人专属显式记忆、一次性提醒，以及经用户确认后才处理的本地附件问答。

本项目与 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 集成，但不隶属于、未获其或《崩坏：星穹铁道》相关权利方的认可。未包含官方角色图片、商标、音频、台词或游戏资源。请遵守适用的平台规则与知识产权规则。

## 设计重点

- 默认保护：未配置精确的主人 ID 时，记忆、提醒和附件功能全部关闭。
- 只接受主人私聊：群聊和非主人的敏感读写被拒绝；可额外限定 AstrBot 的 `platform_id`。
- 自有数据目录：插件只写入 AstrBot 的 `data/plugin_data/astrbot_plugin_himeko/`，不读取你的桌面、个人资料、知识库或其他任意目录。
- 显式记忆：只通过 `/记住` 或明确工具意图保存；拒绝常见密钥、密码、验证码和身份证/银行卡格式内容。
- 附件先确认：附件先在本机解析；只有确认读取后，提取出的文字和问题才会交给当前 AstrBot 对话模型。原始文件会在回答后或超时后删除。
- 提醒不补发：提醒只使用当前进程里重新确认过的主人私聊上下文。重启或上下文失效时标记为未送达，不向旧会话盲目补发。

## 功能范围

| 功能 | 默认值 | 说明 |
| --- | --- | --- |
| 姬子互动补充提示 | 关闭 | 为已配置主人私聊追加通用、非官方的角色表达提示。模型和主人格仍由 AstrBot 配置。 |
| 主人专属记忆 | 关闭 | 手动保存、查看与删除短事实，最多 100 条。 |
| 一次性提醒 | 关闭 | 仅向当前已验证的主人私聊发送一次。 |
| 附件问答 | 关闭 | PDF、DOCX、HTML、Markdown；最大 20 MB；PDF 扫描页 OCR 为可选本地依赖。 |

本插件不提供个人档案读取、云端部署、自动归档、群聊记忆、多用户共享记忆或自动发送给第三方的功能。

## 安装与第一次互动

### 1. 准备 AstrBot 与模型

1. 按 [AstrBot 文档](https://docs.astrbot.app/) 安装并启动 AstrBot。
2. 在 AstrBot WebUI 配置消息平台和模型服务。模型密钥只保存在 AstrBot 自己的配置中，**不要**填进本插件的配置、源码或 issue。
3. 可在 AstrBot 为该私聊配置人格。插件的“姬子互动补充提示”只是一层可关闭的补充，不替代 AstrBot 的模型选择或人格配置。

### 2. 安装插件

公开仓发布后，在 AstrBot 的 `data/plugins` 目录执行：

```powershell
git clone https://github.com/fushuyiliu/astrbot_plugin_himeko.git
```

也可以把本目录整体复制到 `AstrBot/data/plugins/astrbot_plugin_himeko/`。目录根部必须直接包含 `metadata.yaml` 与 `main.py`。

重启 AstrBot，或在 WebUI 的“插件”页面重载插件。AstrBot 会读取 `requirements.txt` 安装基础附件解析依赖。

### 与公开 AstrBot 配置仓协作

本插件仓与公开 AstrBot 配置仓可以配合使用，但保持完全独立：

- **配置仓**只提供已脱敏的 AstrBot 安装说明、平台/模型配置模板与兼容性说明；不得提交主人 ID、模型密钥、平台令牌、真实聊天记录、数据库、日志或生产配置文件。
- **本插件仓**只提供可安装的插件源码、依赖、文档和测试；不得复制配置仓的运行配置或通过 Git 子模块、自动同步脚本读取它。
- 安装顺序为“配置仓的通用 AstrBot 准备步骤 → 安装本插件 → 在本机填入主人 ID 和按需开关”。主人 ID 与任何凭据只保存在用户自己的 AstrBot 配置中。
- 两仓只通过版本说明联动：本插件 1.0.0 要求 AstrBot `>=4.28,<5`。当配置模板或插件安装步骤变化时，才需要同时更新两边的兼容性说明；日常运行数据绝不跨仓提交。

配置仓的正式公开链接将在其远程地址确认后加入此处；在此之前不要根据猜测的仓库地址克隆或配置。

### 3. 配置主人与开关

在 AstrBot WebUI 的“插件 → Himeko Companion → 插件配置”中：

1. 将 `owner_id` 填为消息平台显示的**精确发送者 ID**，不要填昵称、手机号、密码或令牌。
2. 如需限制到一个平台，再填写 `platform_id`；留空表示精确 ID 可在不同私聊平台匹配。
3. 按需开启 `enable_character_prompt`、`enable_memory`、`enable_reminders`、`enable_attachments`。
4. 保存并按 AstrBot 提示重载插件。

所有开关初始为关闭。这是刻意的隐私默认值，而非安装故障。

### 4. 完成一轮互动

向配置的主人私聊发送普通消息。若已开启互动提示，当前 AstrBot 模型会收到该通用提示；如果没有响应，请先检查 AstrBot 的平台、模型和触发规则。

以下示例均为虚构内容：

```text
/记住 喜好 喜欢在晚上整理阅读笔记
/记忆
/提醒 2026-10-07 20:00 整理一页读书笔记
```

## 记忆、提醒与附件

### 记忆

- `/记住 主题 内容`：创建或更新一条记忆。
- `/记忆`：列出当前主人保存的记忆。
- `/忘记 主题`：删除一条记忆。
- `/清空记忆 确认`：删除全部插件记忆。

记忆只对同一平台、同一平台配置和同一主人 ID 的组合可见。它只作为本轮可纠正的参考资料，不是系统指令，也不会自动写入任何外部文档。

### 提醒

- `/提醒 YYYY-MM-DD HH:MM 事项`
- `/提醒列表`
- `/完成提醒 编号`
- `/稍后提醒 编号 分钟`
- `/取消提醒 编号`

时间按 UTC+8 解析。提醒不保证在机器人停机期间投递；重新启动后，请由主人发送一条私聊消息来刷新安全的投递上下文。

### 附件问答

在主人私聊发送支持的附件，再发送问题，或发送：

```text
读取 附件编号 这份虚构报告的三个要点是什么？
确认读取 附件编号
```

PDF 可指定页码，例如 `确认读取 附件编号 1-3,5`。扫描 PDF 会提示是否使用本地 OCR。OCR 默认不安装；只有你确实需要时，才在 **AstrBot 使用的同一 Python 环境** 中运行：

```powershell
pip install -r requirements-ocr.txt
```

可用 `/附件记录` 查看问答索引，`/删除附件记录 编号` 删除该插件保存的问答。删除不会自动清除 AstrBot 聊天历史、消息平台副本、备份或模型服务侧记录。

## 数据与隐私

插件数据位于：

```text
AstrBot/data/plugin_data/astrbot_plugin_himeko/
├── memory.sqlite3
├── reminders/
└── attachments/
    └── 附件问答/
        ├── 临时/
        ├── 记录/
        └── ocr-models/        # 仅使用 OCR 后出现
```

数据流如下：

1. 普通消息由 AstrBot 按你的平台和模型配置处理。
2. 开启记忆后，插件只将保存的短事实作为当前主人本轮的临时上下文交给当前模型。
3. 开启附件后，附件先在本机解析；**确认读取后**，插件把提取文字、文件信息和你的问题交给当前 AstrBot 模型。
4. 提醒内容和记忆保存在本地插件数据目录。附件原文件不作为长期记录保存；问答记录会保留，直到你删除它或删除插件数据。

模型服务、AstrBot 本体和消息平台也可能保有各自的日志或消息历史，请按它们的文档单独配置和删除。不要把秘密、支付信息、身份号码或未获授权的他人资料发送给任何模型服务。

要彻底删除本插件数据：先停止 AstrBot，再删除上面的 `astrbot_plugin_himeko` 数据目录。卸载插件本身不会自动删除数据，以免误删。

## 已验证环境与限制

- 已使用 Python 3.12 与 AstrBot 4.28.1 进行插件入口导入和 8 项单元测试；尚未在独立 AstrBot 实例完成完整消息平台安装验收。
- 不对响应速度、OCR 准确率、提醒准时率或模型输出正确性作性能承诺。
- 附件大小限制为 20 MB；旧版 `.doc`、压缩包和可执行文件不支持。
- 仅测试和支持主人私聊场景。群聊、多人隔离和跨平台同 ID 合并均不在首版范围内。
- “删除”仅针对本插件控制的数据；第三方服务已接收的数据需在各自服务中处理。

常见问题：

- **功能没有反应**：确认 `owner_id` 是精确发送者 ID、消息是私聊、对应开关已开启，并重载插件。
- **插件无法加载**：检查 AstrBot 版本、`requirements.txt` 安装日志和 WebUI 的加载失败信息。
- **OCR 提示依赖缺失**：在 AstrBot 同一 Python 环境安装 `requirements-ocr.txt`，或选择“略过 OCR”。
- **提醒未送达**：重启后主人尚未发送新私聊、会话已失效或平台发送失败时，提醒会安全地标记为未送达。

## 卸载

1. 在 AstrBot 停止或禁用本插件。
2. 删除 `AstrBot/data/plugins/astrbot_plugin_himeko/`。
3. 如果确认不再需要数据，再删除 `AstrBot/data/plugin_data/astrbot_plugin_himeko/`。
4. 如安装过 OCR 依赖，可在 AstrBot 的 Python 环境按你的包管理策略卸载它们。
